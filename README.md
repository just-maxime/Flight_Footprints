# 航班足迹 使用说明

**Flight Footprints User Guide**

---

## 一、这是什么

「航班足迹」是一个单文件的航班记录与可视化工具，打开后可以：

- 记录每一次飞行（日期、航班号、航司、起降地、时间、机型、座位、票价）
- 按年份 / 航司 / 城市筛选与搜索
- 在地图上查看航线网络
- 自动统计飞行次数、总时长、总里程、到访城市、航司分布等

**纯净版的特点：**

1. 只有一个 HTML 文件，不依赖服务器，双击即可使用。
2. 内置 10 条示例数据，仅用于演示，可随时全部删除。
3. 所有数据只保存在当前设备的浏览器里，不会上传，也不会与其他人（包括把文件发给你的人）共享。

---

## 二、怎么打开

**电脑：**

双击「航班足迹-纯净版.html」，用 Edge 或 Chrome 打开即可。

**手机：**

1. 把 HTML 文件发到手机（微信文件传输助手、QQ、网盘均可），保存到「下载」或「文档」目录。
2. 用手机浏览器打开。推荐 Chrome、Edge、小米浏览器、夸克。
3. 若在微信 / QQ 内直接点开，请点右上角「…」→「用浏览器打开」。微信内置浏览器可能清理本地存储，导致数据丢失。

> **提示：** 不需要安装任何软件。地图底图需要联网；完全离线时会自动显示航线示意图，航线和城市点位仍可正常查看。

---

## 三、界面说明

**左侧导航**（手机端在底部）：

- **数据概览：** 飞行总览、航线图、年度航班量、最近记录、航司 Top
- **航班管理：** 完整列表，支持搜索、筛选、排序、分页
- **航线地图：** 全屏航线网络，可按年份筛选，可开关飞行特效与城市标注
- **数据分析：** 年度趋势、航司分布、热门航线、城市频次、机型、票价

**常用操作：**

- **新增：** 右上角「新增航班」，填写后保存
- **编辑 / 删除：** 在「航班管理」每行右侧的图标按钮
- **详情：** 点击任意一行，右侧滑出详情面板

## 四、批量导入

1. 进入「航班管理」，点工具栏的「下载模板」，得到「航班批量导入模板.csv」。
2. 用 Excel / WPS 打开。首行是字段名，请勿改动；第二行是格式示例，正式填写前请删除或覆盖该行。列的顺序可以调整，程序按表头名称识别。
3. **字段说明：**

| 字段 | 必填 | 说明 | 示例 |
|---|---|---|---|
| 日期 | ✅ | 格式 `2026-01-01` | 2026-01-01 |
| 航班号 | ✅ | 与日期一起用于去重 | MU5737 |
| 航空公司 | — | 如 东方航空 | 东方航空 |
| 出发地 | — | 建议写到机场，便于识别城市 | 昆明长水 |
| 目的地 | — | 建议写到机场，便于识别城市 | 广州白云T1 |
| 实际起飞时间 | — | `HH:MM:SS` | 09:15:00 |
| 实际到达时间 | — | `HH:MM:SS` | 11:20:00 |
| 飞行时间 | — | `HH:MM:SS` | 02:05:00 |
| 执飞飞机 | — | 如 波音737-800(WL) | 波音737-800(WL) |
| 飞机编号 | — | 如 B1309 | B1309 |
| 座位号 | — | 如 34A | 34A |
| 含税票价(CNY) | — | 纯数字 | 1280 |

4. 保存为 CSV：在 Excel 中选「另存为」→「CSV UTF-8（逗号分隔）」。若只能存成普通 CSV（GBK 编码）也可以，程序会自动识别。
   > ⚠️ 不要直接导入 `.xlsx` 文件，本版本只支持 CSV / JSON / TXT。
5. 回到页面点「导入」，选择该 CSV 文件。
   > 导入时会自动跳过「日期 + 航班号」相同的记录，同一个文件重复导入不会产生重复数据。

---

## 五、一键清除与恢复

「航班管理」工具栏最右侧的红色按钮「清除全部」：

- 删除当前设备上的全部航班记录，删除后不可恢复。
- 点击后需要在弹窗中确认，建议先「导出 JSON」备份。
- 清除完成后，刷新页面仍保持为空，不会自动恢复。

**清除后想找回演示数据：** 点「恢复示例数据」，会还原内置的 10 条示例。

> ⚠️ 它只恢复示例，不会恢复你删除的个人记录。

## 六、数据存储与备份

**数据位置：** 浏览器本机存储（localStorage），存储键 `flightLog.clean.v1`。不同设备、不同浏览器、不同副本之间互不共享。

**以下情况会导致数据丢失：**

- 清理浏览器数据 / 清理缓存
- 使用无痕（隐私）模式
- 卸载或重装浏览器、更换设备

**备份方式：**

- **导出 JSON：** 完整数据，可在本版本中「导入」还原，也便于长期存档
- **导出 CSV：** 便于用 Excel 查看和编辑

> 💡 建议每次集中录入后导出一次，存到网盘、微信收藏或发给自己。页面顶部蓝色提示条右侧的「导出备份」与工具栏的「导出 JSON」效果相同。

## 七、常见问题

**Q：页面顶部一直显示「数据保存在本机浏览器」，正常吗？**

A：正常。纯净版不连接任何服务器，这是预期状态，不影响使用。

**Q：地图空白，只显示示意图？**

A：底图需要联网。离线时程序会自动切换为示意图，航线和城市点位仍然正常显示。

**Q：导入后中文乱码？**

A：请把文件另存为「CSV UTF-8」。程序也会自动尝试 GBK 编码；不要导入 `.xlsx` 文件。

**Q：为什么地图上没有某个城市？**

A：本版本内置 13 座城市坐标：昆明、曼谷、吉隆坡、清莱、重庆、成都、三亚、南京、无锡、深圳、广州、西安、上海。其他城市可以正常记录、筛选和统计，但地图不显示点位，航距显示为空。

**Q：能和朋友共用同一份数据吗？**

A：不会自动同步。需要一方「导出 JSON」，另一方「导入」来合并；同一天同一航班号的记录会自动跳过。

**Q：在微信里打开后数据丢了？**

A：微信内置浏览器会清理存储。请改用系统浏览器打开，并定期导出备份。

**Q：换电脑 / 换手机后数据还在吗？**

A：不在。数据只存在原设备的浏览器里。请先导出 JSON，在新设备上导入。

---

## 八、使用建议

- 不要删除或重命名 HTML 文件后再打开旧书签，建议固定存放位置。
- 定期导出备份，尤其是在清理浏览器、换设备、系统更新之前。
- 本说明与 HTML 文件放在同一目录，方便一起转发。
- 示例数据可全部删除，删除后即为一份完全属于你自己的空白账本。
